# Legacy Archive

This folder preserves files from earlier iterations of the site that are no longer part of the active Astro build.

- `jekyll-site/` contains the older Jekyll-based site structure, theme overrides, and related notes.
- `talkmap/` contains the historical talk map scripts and generated assets.

The live website is now built from the root Astro application, mainly `src/`, `public/`, `config.yml`, and `astro.config.mjs`.
